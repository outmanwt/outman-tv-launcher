## 构建检查

在仓库根目录执行：

```bash
cd src
./gradlew assembleDebug lintDebug
```

Windows 使用同目录的 `gradlew.bat`。环境要求为 JDK 17、Android SDK 34；Wrapper 对应 Gradle 8.7。

记录本次实际运行的源码版本、命令、退出码、构建时间及 APK SHA-256，不要仅写“构建成功”而无法关联到拟发布文件。若执行独立测试脚本或 Gradle 测试任务，另行记录真实存在的命令与输出，不预设测试数量。

## 动态验收清单

以下各项当前均未声明通过，测试时使用自己控制的设备及有权使用的播放列表。

### 安装与 HOME

- [ ] debug APK 能安装并正常启动；记录设备型号、Android 版本和安装方式。
- [ ] 系统能够识别应用的 HOME 入口；用户可通过正常系统设置选择它。
- [ ] 用户可以通过系统正常机制切回原桌面；不存在强制接管或阻止退出的行为。
- [ ] 应用冷启动、退到后台、再次返回与按 HOME 后的行为符合预期。

### M3U 导入与频道归组

- [ ] 能导入合法测试 M3U，并显示预期的分组与频道。
- [ ] 同组同名条目归为多线路；不同组中的同名频道不会被误合并。
- [ ] 换行、空行与非 ASCII 频道名称的处理符合预期。
- [ ] 空文件、不合法文件和不可播放条目不会引发不可恢复的崩溃。
- [ ] 导入、持久化与再次打开的结果一致，不泄露源地址或凭据。

### 单播放器与生命周期

- [ ] 频道预览和全屏切换使用同一播放器实例，不出现双重声音或重复播放。
- [ ] 切换频道、切换线路、退出全屏与返回首页后，播放状态符合预期。
- [ ] 应用退到后台、恢复、关闭与重启时无残留音频或明显资源泄漏。
- [ ] 播放地址不可用或网络中断时记录真实行为，不把源本身失败误判为播放器通过。

### 应用入口与基本遥控器交互

- [ ] 应用入口可启动实际安装且可启动的应用。
- [ ] 方向键、确认键和返回键完成主要路径，无明显无法退出的状态。
- [ ] 记录当前基础导航问题；本清单不代表已完成焦点专项优化。

### 公开包检查

- [ ] 源码、测试数据、构建输出说明中不包含私有直播源、访问凭据或本地环境信息。
- [ ] 第三方版权与许可文件保留完整，且与实际代码及依赖一致。
- [ ] README、APK 文件名、应用版本与测试记录对应同一版本。
- [ ] 对外明确 debug 测试版及签名未来可能变化，不声明正式稳定或升级签名保证。
